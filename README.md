Social media platforms generate massive volumes of engagement data—likes, comments, shares, impressions, watch time, and more. Analysing such data helps companies understand user behavior, identify trends, and improve content performance. In this assignment, I have worked with a social media dataset containing social media engagement metrics of 5,000 posts to extract insights on what drives audience interaction. Key Libraries used are- 

Pandas & NumPy: For cleaning missing data (using median/mode), correcting outliers (capping engagement metrics), and feature engineering (engagement_score, log transformations).

Matplotlib & Seaborn: For static distributions, correlation heatmaps, demographic profiles, violin plots, and pair plots.

Plotly Express: For an interactive multi-dimensional bubble chart comparing likes, comments, shares, and post categories
